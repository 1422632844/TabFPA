# TabFPA: Tabular Feasibility-Preserving Attack

TabFPA is a research project on feasibility-preserving adversarial attacks on tabular data. This repository will host the project code and experimental materials.

## Status: Under Preparation

The code, experiment configurations, and reproduction instructions are being prepared and are not yet available. This initial repository contains only this README.

The planned release will include the TabFPA implementation, baseline methods, and experimental materials for WiDS, Malware, CTU, and URL. The full code and reproduction materials are planned for release before the full paper submission.

This repository will remain the public location for future releases and updates.
